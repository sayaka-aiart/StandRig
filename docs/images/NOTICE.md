# 掲載画像について

`character-preview.jpg` は、掲載許可を受けたキャラクターPSDをStandRigへ読み込んだ実画面です。ソフトウェアの表示例として掲載しています。

画面内のキャラクター・原画はStandRigのApache-2.0ライセンスの対象外です。キャラクター・原画の権利は各権利者に帰属します。このリポジトリのライセンスは、キャラクター素材の抽出・改変・再配布などの利用許諾を与えません。

元PSD、パーツ画像、編集可能なキャラクターモデルは配布物に含まれません。同梱の図形サンプル `examples/sample.standrig.json` はApache-2.0で利用できます。
