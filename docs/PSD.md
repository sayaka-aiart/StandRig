# PSD入力ガイド

## 用意する素材

パーツ分け済みの `.psd` を1ファイル用意します。描画内容のある画像レイヤーが2つ以上必要です。統合画像だけのPSD、単一レイヤーPSD、空レイヤーを追加しただけのPSD、PSB、PNGの直接読み込みには対応していません。

目・口・前髪・顔・首・体など、別々に動かしたい部位を独立した画像レイヤーにしてください。動いたときに見える裏側や接続部分も描き足しておきます。必要な分け方はモデルと動きによって異なり、レイヤー数だけで適切な分離かは判定できません。

## 読み込みの流れ

1. ブラウザ画面で「PSDを選択」→「PSDを読み込む」。解析はブラウザ内で行われ、取り込んだ画像とモデル構造をローカルサービスへ保存します。
2. 読み込み前のモデルは画像込みチェックポイントに保存します。PSDそのもののバックアップではありません。
3. 表示位置、重なり、色、非表示レイヤーを元画像と比較します。AIはモデルの `importReport` で警告を確認できます。必要な場合だけHTTPの `/api/rig` からレポートを取得します。
4. 参照資料の準備、AIによるモデリング、数値QA、見た目の確認へ進みます。

StandRigにクラウドの画像生成機能は同梱しません。接続したAIクライアントに画像を渡す場合の送信先・取扱いは、そのクライアントの設定に従います。

## Photoshopとの違い

画像レイヤーの画素・位置、グループ階層、表示/非表示、グループを含む不透明度、同階層のクリッピングを取り込みます。通常、乗算、スクリーン、加算（覆い焼きリニア）、覆い焼きカラー、オーバーレイ、ソフトライトに対応します。「通過」以外のグループは内部を合成してから不透明度と描画モードを適用します。クリッピングは基底のアルファを維持し、影や発光を基底の色へ合成します。

外側が黒のビットマップレイヤーマスクは、独立した非表示のアルファ素材として保存します。グループマスクは合成後のグループへ一度だけ適用します。マスク素材も対象と同じ変形へ追従するようにモデリングしてください。無効なマスクは適用しません。外側が白のマスクや画素のないマスクは未対応として読み込みレポートへ記録します。

Photoshopとの完全一致は保証しません。レイヤースタイル、調整レイヤー、ベクトルマスク、テキスト、スマートオブジェクトなどは元PSDとの比較が必要です。

必要な効果を画像レイヤーに反映した**コピー**を用意し、動かす部位同士を統合しないようにしてください。編集用の元PSDは保管します。ビットマップデータのないレイヤーはスキップされる場合があります。

解析はブラウザのメモリを使います。大きなキャンバスや多数のレイヤーに対する上限・性能は未認定です。サービスへ送るモデルJSONには128 MiBのリクエスト上限があり、画像の埋め込みでPSDファイルより大きくなる場合があります。失敗時はエラーを確認し、元PSDを保管したうえで解像度や素材構成を調整してください。非表示フォルダの画像は通常再生時には展開せず、表示可能な不透明度キーや使用中のマスク素材は保持します。

## 保存済みモデルとの区別

素材入力UIはPSD専用です。作業の再開は同じデータフォルダでサービスを起動します。別環境から受け取ったStandRig JSON / bundleの復元は、[APIの再読み込み手順](API.md#bundleの再読み込み)を使います。
